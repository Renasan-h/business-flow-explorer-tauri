# Business Flow Explorer Tauri版 — 仕様・設計

仕様変更時は実装と合わせて更新してください。

## 目的と対象

- 業務処理、事務処理、システム間通信、外部IFの流れを視覚的に設計・編集・再生する。
- シナリオはYAMLで管理する。Tauri 2によるWindowsデスクトップ版を対象とし、Electronは使用しない。
- Web版は別リポジトリ（https://github.com/Renasan-h/business-flow-explorer ）。移植元・参考資料であり、同一仕様を常に保証するものではない。
- インストール不要のPortable ZIPとNSISインストーラーの配布を想定する。現状のZIPはexeの圧縮であり、設定・データを展開先へ閉じ込める「完全ポータブル」仕様ではない。

## 技術構成

- React 19 / TypeScript / Vite 7、描画にSVGとPixiJS 8。
- Tauri 2 / Rust、シナリオ形式はYAML、実行時検証はZod。
- `src/App.tsx`：再生画面とシナリオ選択、`src/FlowEditor.tsx` と `src/editor/`：編集画面。
- `src/scenario.ts`：YAML読込、参照展開、検証。 `src/branchPlayback.ts`：分岐再生の対象抽出。
- `src/editor/scenarioPersistence.ts`：保存経路の振り分け。 `src-tauri/src/lib.rs`：ネイティブのフォルダ・ファイル操作。
- `src/playback/`：再生UI。 `public/scenarios/`：同梱シナリオ。

## YAMLシナリオ

- 親シナリオは `schemaVersion: '1.0'` と `metadata`（`id`, `title`, `description`, `category`）を持つ。
- `actors`：ノード。ID、名前、種別、位置、サイズ、説明、環境、接続先、IP、タグ、関連資料等を設定可能。
- `steps`：通信ステップ。配列の記載順が再生順。各ステップの `actions` に送信元・送信先・内容・所要時間を定義。
- 双方向通信は `bidirectional`、`reverseFrom`、`reverseTo` 等で復路を指定。復路が不完全な場合は再生開始時に検証する。
- 通信線は `routing: straight | orthogonal`。手動経由点 `waypoints` と復路 `reverseWaypoints` はそれぞれ最大100件。
- `branchLabel` とdecisionノードによる分岐再生、`groups` による領域、`interfaces` によるIF定義に対応。
- `actorFiles`、`actors: - file: ...`、`steps: - file: ...` による参照をサポート。参照は記述元ファイルからの相対パス、選択ルート外への逸脱と循環参照は禁止。
- 親ファイルと参照断片は役割が異なる。`steps[].file` 参照先に `schemaVersion/metadata` を持つ親シナリオを指定すると厳密読込では拒否する。編集用読込では復元可能な範囲を表示し、再生を停止する。テンプレートは親シナリオ形式を要求する。
- 同梱シナリオの読込時は原則ノード2件以上・通信1件以上。ローカル編集中のドラフトには例外がある。

## 画面と操作

### 編集

- ノード・通信線・領域・IF定義の追加、編集、削除。
- ノード複数選択、範囲選択、Shift操作、ドラッグ移動。ノードサイズと色の変更。
- キャンバスの拡縮、パン、負座標を含む配置。初期表示はノード配置範囲に合わせて中央寄せする。
- 通信線の経由点、往復別の編集、再生順マーカーと順序変更。
- Ctrl+Z / Ctrl+YによるUndo/Redo。
- ノード選択中はBackspace/Deleteで削除確認を表示し、確定時に関連通信も削除。複数選択は一括削除し、入力欄やダイアログ操作中はショートカットを無効化する。
- 未保存変更の確認、保存前検証、外部更新との競合検知。保存失敗時は編集中の内容を保持する。

### 再生

- 通信を順にアニメーション再生し、再生・一時停止・速度変更・ステップ操作を提供。
- 双方向通信は往路と復路を扱う。最終ステップ終了時は停止。
- Technical / Illustration表示、テーマ切替、ズームと移動、ノード詳細・IF情報の表示。
- 分岐選択時は選択されなかった経路の通信・ノードを再生対象から除外する。

### シナリオ管理

- 同梱シナリオとユーザーが選択したローカルフォルダ内のYAMLを表示。
- テンプレート取込、共通Actor、分割参照に対応。
- ネイティブ保存は選択フォルダ内に限定し、既存ファイルの期待内容を確認して競合を検出する。
- ブラウザ実行時はネイティブファイル操作と同一ではないため、ファイルピッカーまたはダウンロードへ分岐する。

## 設計・変更時の注意

- 画面上の表示、保存YAML、再読込、再生結果をセットで検証する。
- 無限キャンバス、縮尺30%でのノード移動、負座標、通信線の往復、経由点の編集を回帰確認する。
- シナリオ参照はベースディレクトリ外に出さない。ID重複、存在しないActor、非有限座標、サイズ制限等を確認する。
- 編集・再生画面間の遷移で未保存の変更を失わない。保存競合時に外部変更を無断上書きしない。
- YAMLや操作の詳細は `docs/user-guide.md`、開発・CI・ビルド手順は `docs/development.md` を参照する。

# 操作ガイド

## 1. シナリオを開く

起動後、同梱シナリオを一覧から選択すると再生画面に表示されます。ローカルのYAMLを編集する場合は **「ローカルのシナリオフォルダを開く」** から対象フォルダを選択します。フォルダ配下の `.yaml` / `.yml` が読み込み対象です。

同梱シナリオはアプリから直接上書きしません。編集したYAMLは別ファイルとして保存してください。

## 2. フローを編集する

**「✎ フローを編集」** または **「新規」** から編集画面を開きます。

| 操作 | 方法 |
|---|---|
| ノード追加 | 「＋ ノード追加」 |
| ノード移動 | 「移動・選択」でノードをドラッグ |
| 複数選択 | 「複数ノード選択・移動」で範囲選択、Shift＋クリックで追加・解除 |
| 通信線 | 「通信線を追加」で送信元・送信先を指定。接続ハンドルのドラッグにも対応 |
| 領域 | 「＋ 領域追加」 |
| IF定義 | 「＋ IF定義」 |
| テンプレート | 「テンプレートの読み込み…」 |
| 拡大・縮小 | ツールバーの「＋」「−」またはCtrl＋ホイール |
| 表示位置を戻す | 「表示リセット」 |
| 元に戻す・やり直し | Ctrl＋Z / Ctrl＋Y |
| 再生順の変更 | 「再生順を並べ替え」または右側の再生順一覧 |
| プレビュー | 「▶ プレビュー」 |

通信線の往路・復路、折れ線の経由点、ノード・領域のプロパティは編集画面の設定UIで変更します。再生順の番号は通信線上でドラッグして並べ替えられます。

## 3. 再生する

再生画面でシナリオを選択し、再生・停止・速度切替を操作します。分岐を持つシナリオでは分岐先を選択して再生します。ノードやIF情報を選択すると詳細を参照できます。

## 4. YAMLを保存する

編集画面の「YAMLを保存…」から保存します。

- 選択したローカルフォルダ内の**新規フロー**は新しいYAMLとして作成します。
- **既存フロー**は読み込み時の原文と保存先を比較してから更新します。
- 他のアプリが先にファイルを更新した場合は**保存競合**となり、外部の変更を無断で上書きしません。
- 編集画面を離れる際に未保存の変更がある場合は確認ダイアログが表示されます。破棄前に内容を確認してください。
- 同梱シナリオやブラウザ実行時の保存は、ファイル選択またはダウンロード方式になります。

重要なYAMLは保存前にバックアップしてください。保存競合が出た場合は、外部で変更されたファイルと現在の編集内容を比較してから作業を再開してください。

## 5. YAMLの基本形

```yaml
schemaVersion: '1.0'
metadata:
  id: sample
  title: サンプル
  description: シンプルな通信
  category: examples
actors:
  - id: web
    name: Web
    type: browser
    position: { x: 0, y: 0 }
  - id: api
    name: API
    type: api
    position: { x: 300, y: 0 }
steps:
  - id: request
    title: API呼び出し
    description: WebからAPIへ
    actions:
      - type: transfer
        from: web
        to: api
        payload: request
        durationMs: 800
```

**注意**：`type` はアプリが定義するノード種別を指定してください。詳細な実例は `public/scenarios/` を参照してください。Actorやstepの `file` 参照は参照元ファイルからの相対パスです。参照先が選択中のシナリオルート外に出る構成は許可されません。

## 6. トラブルシューティング

- **YAMLを開けない**：必須項目・ノード種別・参照先ファイルの有無を確認します。
- **保存競合**：別アプリによる更新が発生しています。上書きせず差分を確認します。
- **フォルダを開けない**：Tauriデスクトップ版か確認します。ブラウザのみの起動ではネイティブAPIを利用できません。
- **再生時のエラー**：通信元・通信先、双方向設定、分岐、IF参照を確認します。

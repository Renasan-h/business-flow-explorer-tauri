# Business Flow Explorer v0.1.0 — リリースノート案

> **公開前のドラフト**：Windows実機のP0受け入れ試験と最新コミットのCI成功は未確認です。正式公開時は結果・既知の問題を更新してください。

## 主な機能

- YAMLで業務フロー・システム間通信を定義し、ノードと通信線として可視化。
- ノード・通信線・領域・IF定義の編集、再生順の変更、経由点、双方向通信、Undo/Redo。
- 再生、一時停止、速度変更、分岐の選択、ノード詳細・IF資料の参照。
- ローカルフォルダのYAML読込・保存、サブシナリオ・共通Actorの参照、保存競合の検知。

## 配布形式

- **Windows NSISインストーラー**：インストールして起動する形式。
- **Portable ZIP**：展開したexeを直接起動する形式。アプリ設定やシナリオデータの保存場所までZIP内に固定する「完全ポータブル」仕様ではありません。

## 動作環境

- Windows 11 x64を検証対象とする。WebView2ランタイムが必要。
- Windows 10やARM64など、上記以外の環境は未検証。

## インストールと利用開始

1. GitHub ReleasesからインストーラーまたはPortable ZIPを取得する。
2. インストーラーの場合はインストールして起動。ZIPの場合は任意のフォルダに展開し、`Business Flow Explorer.exe` を実行する。
3. 同梱シナリオを開くか、YAMLを保存するローカルフォルダを選択する。
4. 操作方法は `docs/user-guide.md` を参照する。

## 既知の制限と注意事項

- Portable ZIPはexe単体を圧縮したもので、設定・データの完全な持ち運びは保証しない。
- 署名対応は未実装。Windowsのセキュリティ警告が表示される可能性がある。発行元が確認できないファイルは実行しないこと。
- READMEの画面画像はWeb版から取得した参考画像であり、Tauri版の実際のUIとは異なる場合がある。
- 正式リリース前に、Windows実機で起動・保存・再起動・競合処理を確認する必要がある。
